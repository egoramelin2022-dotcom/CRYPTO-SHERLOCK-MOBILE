# EXPERIMENT_PROTOCOL — протокол исследований

Версия: 0.1.0

## Цикл
Observation → Candidate Pattern → Hypothesis → Pre-registration → Experiment → Validation → Result → Knowledge.

## Карточка гипотезы
ID/дата; формулировка; рынок/символ/таймфрейм; наблюдаемые условия; момент доступности; прогнозируемый outcome и горизонт; критерии подтверждения/опровержения; baseline; предполагаемый механизм; ограничения.

## Discovery
Допускаются similarity search, nearest neighbours, clustering, change-point detection, anomaly detection, комбинации признаков и sequence methods. Длина окна выбирается из заранее определённых коротких/средних/длинных диапазонов. Масштаб цены и волатильности нормализуется, чтобы сравнивать сопоставимые структуры.

## Исторические аналоги
Для каждого сохранять timestamp, диапазон, similarity score и метод, рыночный режим, доступные признаки, исходы на нескольких горизонтах, MFE/MAE, drawdown, время до результата, издержки и quality flags. Перекрывающиеся аналоги не считать независимыми без поправки.

## Pre-registration
До просмотра holdout фиксируются правила включения аналогов, метрика сходства, пороги, горизонты, метрики успеха, baseline и временные границы. Изменение после просмотра holdout — новая гипотеза и новый независимый эксперимент.

## Обязательные проверки
Хронологические split, walk-forward, baseline, комиссии/проскальзывание, чувствительность параметров, устойчивость по окнам и режимам, множественные сравнения, неопределённость.

## Пятиэтапная формация
Сохранить отдельным режимом:
1. предварительное снижение;
2. восстановление;
3. вершина;
4. резкий обвал;
5. боковик с нижними тенями.

Все пять этапов имеют равный вес в этом режиме. Основной Pattern Intelligence ищет свободно, без обязательного порядка этих этапов. Результаты двух режимов сравниваются отдельно.

## Отчёт
Вопрос и гипотеза; версии данных/кода/параметров; размер выборки и независимых эпизодов; метрики с издержками; интервалы неопределённости; baseline/challenger; разрезы по режимам; ограничения; вердикт supported / not supported / insufficient data; следующий эксперимент.

Запрещено выбирать аналоги по будущему результату, менять критерии после просмотра holdout, скрывать неудачные эксперименты или приравнивать количество свечей к независимым наблюдениям.
