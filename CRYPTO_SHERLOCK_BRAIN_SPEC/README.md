## Обязательные принципы
1. Исходные CSV и SQLite — read-only на этапе разработки; результаты хранить отдельно.
2. Никаких реальных ордеров: только research, backtest и paper trading.
3. Признаки доступны только на момент решения; outcome labels хранятся отдельно.
4. Ни одна закономерность не считается доказанной по обучающей выборке.
5. Эксперименты воспроизводимы: фиксируются данные, код, параметры, seed и временные границы.
6. Новая модель не заменяет Champion без независимого сравнения.
7. Sherlock вправе воздержаться от прогноза при недостатке данных или высокой неопределённости.

Документы фиксируют целевую архитектуру, но не означают, что описанные компоненты уже реализованы или протестированы. Перед изменением кода необходим аудит локального состояния репозитория.
