# SYSTEM_REQUIREMENTS — системные требования

Версия: 0.1.0

## Известная целевая машина
Ранее обсуждались Windows 10, Intel Core i5-2400, 16 GB RAM, AMD RX 580 8 GB, SSD/HDD. Перед настройкой производительности подтвердить конфигурацию. Наличие RX 580 не гарантирует поддержку выбранного ML GPU stack.

## Вычислительная стратегия
На старте CPU-first: SQLite, потоковая обработка, NumPy/Pandas или экономные альтернативы, scikit-learn/градиентный бустинг при совместимости, batch processing и кэширование. Ограничивать параллелизм по RAM/CPU. GPU включать только после проверки драйверов, библиотек и измеренного ускорения.

## Данные и диск
Не копировать исходные данные без необходимости. Ограничивать feature cache и временные файлы. Для артефактов хранить manifest/checksum. Автоматическое удаление исходных данных запрещено. Research DB и model registry резервировать.

## Среда
Версию Python зафиксировать после аудита. Зависимости закреплять. Команды setup/test документировать для PowerShell. Конфигурация через env/config без секретов в Git. Логи ротировать.

## Сеть и удалённый доступ
Синхронизация ограничивает частоту запросов и поддерживает resume. Ошибки источника не выдаются за полную историю. Web/API не публикуется без аутентификации, TLS и ограничений. Секреты не попадают в логи или репозиторий.

## Масштабирование
Начать с BTCUSDT 15m и сопоставимых таймфреймов. Расширяться до 50–100 активов после проверки конвейера и оценки ресурсов. Облако — опционально, не обязательное условие первого ядра.

## Режим торговли
Только research, backtest и paper trading. Реальные торговые API, ключи и отправка ордеров не входят в текущую спецификацию.
